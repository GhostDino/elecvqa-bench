## A3. T3 数值不一致 -> RQ2 分解

**状态：已解决（根因定位 + 修复）**

根因：Unicode 编码不匹配
- GT 标签：corrosao（带 combining tilde，NFKD 编码）
- CNN 预测日志：corrosao（ASCII，无 tilde）
- 导致 184 个 corrosao 样本在部分评估中被误判为错误

修复：NFKD 归一化后，Table 2 / Table 7 / Table A5b 三者完全一致。

| ResNet-50 448px | Table 7: 81.1% / Table A5b: ? | 81.08% |
| Swin-T 448px | Table 7: 54.2% / Table A5b: 75.9% | 75.12% |

论文已更新 Table A5b 脚注和 Limitation (g)。
