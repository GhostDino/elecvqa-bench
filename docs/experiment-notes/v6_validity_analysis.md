# ElecVQA-Bench v6 实验效度分析

**分析框架**: Internal Validity(内部效度), Construct Validity(构念效度), External Validity(外部效度)
**分析日期**: 2026-09-03
**分析版本**: v6（所有 P0 问题已解决后的最终版）

## 一、Internal Validity (内部效度)

> 因果推断是否成立? 实验内部是否排除了混淆变量?

### 1.1 已妥善控制的混淆变量

| 混淆变量 | 控制方式 | 评价 |
|---------|---------|------|
| 评估划分不一致 | 对齐到同一 T2/T3 测试集 + McNemar 配对检验 | 充分 |
| 答案空间基数 | K=2/3/7 三级比较, 同一测试集 | 充分 |
| 输入分辨率 | 四级分辨率阶梯 + VLM 单tile控制 + 672px McNemar | 充分 |
| 语言grounding | P1 vs P3 四格消融(P1训练+P1推理, 消除train-test不匹配) | 充分 |
| 量化精度 | bf16/INT8/NF4 三档 + McNemar | 充分 |
| 长尾类别权重 | peeling-paint(n=4)贡献分解 | 充分 |
| Unicode编码不一致 | NFKD归一化修复 | 已修复 |

### 1.2 仍然存在的内部效度威胁

#### IV-1. 所有VLM结果仍为单种子 (严重)

**威胁**: seed=42的所有VLM结果(Tables 2,7,9b,10,10b)可能是幸运种子。seed=41因swift infer推理退化失败。

**具体风险**:
- Table 6c的0.03点平局在另一个种子下可能变为1-2点差异
- Table 3b的McNemar p=1.0基于单种子配对预测
- P1消融的14.3%崩溃虽然效应量大(63.6点), 但缺乏种子重复验证

**严重程度**: 高。这是审稿人最可能攻击的点。

#### IV-2. 训练配置不匹配未完全控制 (中等)

**威胁**: CNN(10 epochs, cross-entropy, ImageNet) vs VLM(3 epochs, LoRA, 自回归)的训练配置差异未被控制。
分辨率控制的结论448px是最优可能受到CNN的10-epoch训练策略影响。

**严重程度**: 中。论文已声明此限制, 结论方向不太可能反转。

#### IV-3. VLM单tile控制的训练-推理不匹配 (轻微)

**威胁**: VLM用动态分块训练, 单tile控制在推理时强制为单tile 448px。
**缓解**: P1消融已证明train-test不匹配影响极小(0.05点)。
**严重程度**: 低。p=0.00004仍显著。

#### IV-4. 杆塔级数据泄漏 (中等)

**威胁**: 同一物理杆塔的多张照片可能分属训练集和测试集。VLM和CNN的泄漏可能不对称。
**严重程度**: 中。绝对精度可能被高估, 相对比较如果泄漏对称则不受影响--未验证。

#### IV-5. 28点下降未解释 (轻微但令人困惑)

**威胁**: ResNet-50在7851项文件上82.1% vs 7284项T3文件上57.4%, 差28点。论文说无法解释。
**严重程度**: 低(Table 6a已标记为审计失败), 但读者会质疑数据管道可靠性。

## 二、Construct Validity (构念效度)

> 测量是否真正捕获了想要测量的构念? 操作化定义是否合理?

### 2.1 构念定义合理的方面

| 构念 | 操作化 | 评价 |
|------|--------|------|
| 缺陷检测能力 | T2二分类BalAcc + 漏检率 + 幻觉率 | 充分, 多维测量 |
| 细粒度分类能力 | T3 K=7 BalAcc + macro-F1 + 逐类召回 | 充分 |
| 弃权行为 | gamma_D + gamma_N恒等式反推 + 可行区间 | 合理(但非实测) |
| 代价敏感风险 | rho*交叉点 + pi_D流行率敏感性 | 充分 |
| 语言grounding的作用 | P1 vs P3四格消融 | 充分(控制实验) |
| 分辨率的作用 | 四级阶梯 + VLM单tile + McNemar | 充分 |

### 2.2 构念效度威胁

#### CV-1. VLM与CNN的K=7不是同一个构念 (严重)

**威胁**: VLM的K=7是多个K=2/K=3/K=4多选题的复合(每题2-4个动态选项); CNN的K=7是真正的7类分类。
VLM有信息优势: 通过动态选项知道哪些缺陷类型对当前资产是可能的。

**量化**: CNN不可能类别错误仅7个(0.1%), oracle修正后+0.5点。影响微小但构念不等价是原则性问题。
**论文处理**: Limitation(p)已声明并量化。但Table 7的K=7行仍直接比较两者。
**严重程度**: 中。影响微小但审稿人会注意原则性问题。

#### CV-2. VLM优于CNN的构念被过度简化 (中等)

**威胁**: 实际比较的是InternVL3.5-8B+LoRA vs ResNet-50/Swin-T, 不是VLM vs CNN类别层面的泛化。
如果用LLaVA或GPT-4V代替, 结论可能不同。
**严重程度**: 中。论文已降调为boundary condition而非verdict。

#### CV-3. 弃权率的操作化不完整 (中等)

**威胁**: gamma_D和gamma_N通过恒等式反推, 非实测。无法区分模型主动弃权和格式解析失败。
**严重程度**: 中。方向性结论不受影响, 数值精度受限。

#### CV-4. 缺陷定义的构念混淆 (轻微)

**威胁**: P3提示同时包含资产类型描述+缺陷定义+决策树。P1消融去掉了全部三类, 无法分离哪一类起作用。
**严重程度**: 低。效应量太大(63.6点), 细分不影响结论。

#### CV-5. 部署可行性构念缺失 (中等)

**威胁**: 只测了显存, 没有延迟/吞吐/能耗。部署可行性构念未完整操作化。
**严重程度**: 中。不影响方法论结论, 影响实用性建议。

#### CV-6. 现场缺陷流行率的构念映射不确定 (轻微)

**威胁**: 1%现场流行率是假设值, 非实测。实际可能从0.01%到5%不等。
**严重程度**: 低。已做流行率敏感性分析(Table 1d)。

## 三、External Validity (外部效度)

> 研究结果能否推广到其他情境?

### 3.1 外部效度较好的方面

| 方面 | 评价 |
|------|------|
| 数据集公开性 | InsPLAD公开可复现 |
| 代码和权重发布 | 构建脚本/划分清单/提示模板/适配器权重全部发布 |
| 评测框架 | parity-audit程序可应用于任何VLM-vs-CNN比较 |
| 方法论贡献的泛化性 | 三个变量的敏感性分析方法可推广 |

### 3.2 外部效度威胁

#### EV-1. 单一数据集 (严重)

**威胁**: 所有结果仅在InsPLAD(巴西电力线路巡检)上验证。资产类型/缺陷类型/采集条件/气候环境均特定。
在变电站巡检/配电线路/不同地理区域上结论可能不同。
**严重程度**: 高。评测类论文最常见的外部效度限制。

#### EV-2. 单一模型家族 (中等)

**威胁**: VLM侧主要用InternVL3.5系列; CNN侧仅ResNet-50和Swin-T, 未测试ConvNeXt/ViT/EVA。
**严重程度**: 中。zero-shot评测了7个模型, 但SFT后核心实验只用3个。

#### EV-3. 缺陷类型覆盖有限 (中等)

**威胁**: InsPLAD的6种缺陷不覆盖绝缘子破损/闪络/导线断股/金具松动/油位异常/过热等常见缺陷。
**严重程度**: 中。数据集限制而非方法论限制。

#### EV-4. 448px最优分辨率的泛化性不确定 (轻微)

**威胁**: 448px最优可能特定于InsPLAD的图像分辨率(1920x1080)和缺陷视觉特征。
**严重程度**: 低。论文未声称448px是通用最优。

#### EV-5. 缺失真实部署环境验证 (中等)

**威胁**: 所有推理在工作站GPU上运行, 未在无人机机载平台或边缘设备上验证。
INT4零损伤的结论在不同推理框架和硬件上可能不成立。
**严重程度**: 中。论文已声明(Limitation i)。

#### EV-6. 实验时间窗口的外部效度 (轻微)

**威胁**: VLM领域发展极快, 论文使用的模型到发表时可能已过时。
**严重程度**: 低。方法论贡献不依赖具体模型。

## 五、总结

### 论文最强的方面

1. **自我审计的诚实度**: 主动公开错误(划分错配/K=3K=7混淆/Unicode编码), 把审计过程作为方法论贡献
2. **因果分离**: 三因素分离(分辨率/语言grounding/模型规模)是本文最强贡献, 每个因素都有控制实验
3. **统计严谨性**: 所有核心比较都有McNemar配对检验, 量化实验从S200升级到全量测试集
4. **代价敏感框架**: 弃权感知的风险分析填补了工业巡检VQA评测的空白

### 论文最脆弱的方面

1. **单种子**: 所有VLM核心结论依赖seed=42, 最大的内部效度威胁
2. **单一数据集**: 所有结论仅在InsPLAD上验证, 外部效度受限
3. **构念不等价**: VLM和CNN在K=7上解决的不是同一个任务, 虽然影响微小但原则性问题存在

### 给审稿人的防御策略

- **单种子**: sanity check(Table 12)显示S200与full test仅差0.6点; McNemar检验是配对的(控制了样本间变异); swift infer退化是工程问题不是统计问题
- **单一数据集**: 本文的贡献是方法论(parity audit + 代价敏感框架), 不是SOTA模型; 方法论在InsPLAD上的验证足以证明其价值
- **构念不等价**: 已量化(0.1%不可能类别错误, +0.5点oracle修正), 影响远小于分辨率效应(23.7点)
